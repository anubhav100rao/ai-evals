Architecture

What happens when a customer sends a message

Five stages, each traced. The agent loop lets the model call any of 16 tools, which talk to simulated backend services. Every box sends OpenTelemetry spans to Phoenix.

Offline evals

How an experiment scores the agent

The same 34 hand-written cases run against every version of the agent. Each answer is scored by 6 code checks and 3 LLM judges, and Phoenix stores every score, explanation and trace.

flowchart TB
  subgraph IN["1 · Test cases"]
    direction LR
    DS[("Golden dataset<br/>34 cases · 7 categories")]:::data --- CASE["Each case defines: reference answer · expected / forbidden tools<br/>should_escalate · must / must-not mention"]:::note
  end
  subgraph RUNS["2 · Run and score every case"]
    direction LR
    RUN["Run the agent"]:::agent --> OUT["Answer +<br/>full trace"]:::io
    OUT --> CODE["6 code evaluators<br/>tool_recall · forbidden_tools · escalation<br/>key_facts · privacy_guard · protocol"]:::tool
    OUT --> JUDGE["3 LLM judges<br/>correctness · groundedness · tone"]:::llm
  end
  subgraph DEC["3 · Decide"]
    direction LR
    EXP["Phoenix experiment<br/>score + explanation per case"]:::px --> CMP{{"Compare versions<br/>v1 vs v2 · LibreChat vs Sol"}}:::agent
    CMP -- "better on every slice" --> SHIP(["Ship"]):::good
    CMP -- "a slice got worse" --> FIX(["Fix and re-run"]):::bad
  end
  IN --> RUNS --> DEC

Each column's judges use that setup's model, so compare LLM-judge scores within a setup. Code checks compare cleanly across all four.

STORY A

The prompt matters

Asked for an Amazon scraper, the naive v1 prompt wrote the code. v2 declined. v2 scores 1.00 on every code check on both setups, and groundedness goes 0.82 → 0.94.

STORY B

Better model ≠ better at everything

On GPT-6.2 Sol, v2 scored lower on correctness (0.75 vs 0.83). The judges say its "2–5 sentences" rule makes answers concise but incomplete.

STORY C

The eval caught my regression

Adding 8 tools dropped protocol 1.00 → 0.85. The cause: triage notes placed after the "reply only in JSON" rule. Moving one paragraph fixed it.

Online evals and the improvement loop

Production failures become tomorrow's test cases

Production has no reference answers, so reference-free evals score every traced turn and write annotations back onto the trace. A flagged trace becomes a golden case with one click.

flowchart TB
  subgraph BEFORE["Before release · offline"]
    direction LR
    CH["Change something<br/>prompt · tools · model"]:::agent --> EX["Offline experiment<br/>34 golden cases"]:::px
    EX --> CP{{"Better on every slice?<br/>no → change again"}}:::agent
    CP -- "yes" --> SH(["Ship"]):::good
  end
  subgraph AFTER["After release · online"]
    direction LR

    FL --> AD["Add to dataset (one click)<br/>↺ becomes a golden case<br/>for the next experiment"]:::data
  end
